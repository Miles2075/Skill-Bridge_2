# Skillbridge frontend demo

A standalone, responsive UI/UX presentation built with plain HTML, CSS and JavaScript. It uses sample learner, course, assignment and progress data only. Navigation, course search and demo actions work locally.

## Run

Open `index.html` directly in a browser, or serve the repository root with any static file server and visit `/demo/`.

No backend, database, authentication provider or payment gateway is required. Login, enrollment, submissions, certificates and progress are illustrative only; no real account or transaction is created.

The original application source and `main` branch are preserved. This presentation lives on `frontend-demo-only`.
